# CueFlow AI

**Your AI Scriptwriter & Teleprompter** — a Zelven Labs project.

## Current foundation
- React + TypeScript + Vite
- Dark navy and orange interface based on the founder-approved reference
- Script idea input, script type and tone controls
- Editable script workspace with copy and clear actions
- Responsive sidebar/workspace layout

## Run locally
```bash
npm install
npm run dev
```

## Build check
```bash
npm run build
```

> Current script generation is a UI prototype with a local starter script. AI provider integration and recording/teleprompter workflows will be added in later founder-approved steps.
